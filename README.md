# WebApp example piggy bank

## To use on a Apple mobile device
Open https://heikogoelzer.github.io/piggybank/ in safari browser <br>
Share -> Add to Home Screen <br>


## Features
Apple requires settings in index.html to use icon and title when installing the WebApp <br>
Android/Google requires manifest.json to use icon and title when installing the WebApp <br>
Using a service worker to cache app content for offline use <br>


## Preparation on GitHub
Share on github.io per https://github.com/heikogoelzer/piggybank/settings/pages <br>
Deploy from a branch --> Choose branch 'main' <br>
